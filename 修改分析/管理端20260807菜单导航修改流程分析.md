# 管理端菜单导航修改流程分析

日期：2026-08-07

## 需求

导航区域最多只允许一个一级菜单的子菜单展开。

## 状态链路

```mermaid
flowchart LR
  A[点击一级菜单A] --> S[expanded = Set\(A\)]
  S --> B[点击一级菜单B]
  B --> T[expanded = Set\(B\)]
  T --> C[A自动收起，仅B展开]
  S --> D[再次点击A]
  D --> E[expanded = 空集合]
```

通过标签页或首页跳转打开子菜单时，同步定位其所属一级菜单并关闭其他菜单。

涉及文件：`frontend/src/AdminView.vue`。不涉及接口和数据库表字段。
