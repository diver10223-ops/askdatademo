# 管理端 20260807 数据源配置接口库表修改

新增 `GET/POST /api/v1/admin/phase2/datasources`、`POST /api/v1/admin/phase2/datasources/{id}/enable`、`POST /api/v1/admin/phase2/datasources/{id}/diagnose`。新增 `phase2_datasource_configs` 表；公开连接参数和加密密码分列保存。

## 库表字段与关联

| 表 | 字段 | 关联 | 说明 |
|---|---|---|---|
| `phase2_datasource_configs` | `id` | `phase2_provider_profiles.public_config.datasource_config_id` | 数据源主键 |
| `phase2_datasource_configs` | `name, type, status` | 管理端和组合候选 | 名称、CLICKHOUSE/MYSQL及生命周期 |
| `phase2_datasource_configs` | `public_config` | 组合及数据源Provider | JSON保存地址、库、表白名单和安全策略 |
| `phase2_datasource_configs` | `encrypted_credentials` | 仅服务端解密 | 加密数据源密码 |
| `phase2_datasource_configs` | `created_at, updated_at` | 审计 | 时间字段 |
| `audit_logs` | `action, actor, detail, created_at` | `detail.id`关联数据源ID | 创建操作记录 |

`public_config` JSON字段包括：`url`、`host`、`port`、`tls`、`username`、`database`、`allowed_tables`、`read_only`、`charset`、`pool_size`、`schema_sync`、`max_rows`、`max_time_range_days`、`timeout`、`retries`、`max_concurrency`。

## 接口影响

| 方法和路径 | 请求字段 | 关联功能 |
|---|---|---|
| `POST /phase2/datasources` | `name, type, url/host/port, username, password, database, allowed_tables`及策略字段 | 独立新增 |
| `GET /phase2/datasources` | 无 | 列表和组合候选 |
| `POST /phase2/datasources/{id}/enable` | `id` | 独立启用 |
| `POST /phase2/datasources/{id}/diagnose` | `id` | 健康与Schema诊断 |
## 运维监控补充

- 接口：`GET /api/v1/admin/logs?kind=source-monitor`、`GET /api/v1/admin/logs/source-monitor/{id}`。
- 主表：`sql_executions`；关联：`requests`、`sessions`。
- 展示字段：`source`、`status`、`row_count`、`elapsed_ms`、`fallback`、`business_sql`、`actual_sql`、`error`、`created_at`。
- 对接表字段：`phase2_datasource_configs.public_config.allowed_tables`，派生“关联数据表”和“表数量”。
