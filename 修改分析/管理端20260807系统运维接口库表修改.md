# 管理端 20260807 系统运维接口库表修改

新增 `POST /api/v1/admin/phase2/providers/compose`，入参为组合名称、模型配置ID和数据源配置ID。接口仅接受两项已启用配置，并生成兼容运行Profile；会话相关表不变。

## 关联库表字段

| 表 | 读取/写入字段 | 关联关系 |
|---|---|---|
| `phase2_model_configs` | 读取 `id, provider, public_config, encrypted_credentials, status` | `id = model_config_id`且必须启用 |
| `phase2_datasource_configs` | 读取 `id, type, public_config, encrypted_credentials, status` | `id = datasource_config_id`且必须启用 |
| `phase2_provider_profiles` | 写入全部字段 | `public_config`记录两个来源ID，凭据重新加密 |
| `phase2_session_profiles` | `session_id, profile_id, execution_mode` | `profile_id`引用组合Profile |
| `sessions` | `id` | 被 `phase2_session_profiles.session_id` 引用 |
| `provider_diagnostics` | `profile_id, component, status, detail, created_at` | 保存组合诊断结果 |
