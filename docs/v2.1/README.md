# AskData 产品 V2.1 多任务设计文档

本目录保存 V2.1“多任务优化、用户体验、多任务执行”的演示与技术设计基线。

## 文档清单

1. `01-NLQ产品V2.1多任务优化-8大标准演示场景完整清单.docx`
   - MT01—MT08 八个全新多任务演示场景。
   - 包含三角色差异化效果、逐场景七层行为、现场话术和验收检查点。
2. `02-NLQ产品V2.1七层架构-8大多任务完整输入输出标准案例.docx`
   - 包含八场景逐层输入、处理、输出、JSON示例、状态机和错误码。
3. `03-NLQ产品V2.1七层架构技术实现详设文件-完整落地版.docx`
   - 包含总体架构、领域对象、库表、七层详设、DAG调度、安全、接口、可观测、测试和实施分解。
4. `04-V2.1多任务七层逻辑与全量修改影响分析.md`
   - 对照现有 V2.0 实现，说明七层、数据库、接口、前后端、管理端、运维、测试和发布的修改范围。
5. `05-AskData产品V2.1需求规格说明书.md`
   - V2.1正式需求细化稿，包含范围、第一轮核心执行规则、功能需求、七层、数据库、接口、非功能、四状态、验收和待确认事项。
6. `06-AskData产品V2.1新增场景与初始化数据设计.md`
   - 定义MT01—MT08场景、任务能力、计划模板、指标数据、Demo Fixture、POC黄金数据和Product初始化边界。
7. `07-AskData产品V2.1执行计划与步骤说明.md`
   - V2.0关闭后执行的M0—M7开发、测试、验收和发布步骤及任务清单。
8. `08-V2.1八场景标准脱敏演示数据基线.md`
   - 方案A确认后的机构、指标、周期、标准数值、故障和三角色期望；对应机器数据在`fixtures/demo/v2.1/baseline.json`。
9. `09-V2.1外部API与Java-Python内部契约设计.md`
   - V2.1外部接口、计划契约、SSE、Java/Python命令、错误码和兼容安全规则。
10. `10-V2.1数据库逻辑模型与迁移详细设计.md`
    - 新增/调整表、状态、事务、一致性、归档恢复和迁移验证。
11. `11-V2.1用户端与管理端交互规格.md`
    - 计划卡、任务卡、结果区、任务中心、管理端及九类待制作高保真页面。
12. `12-V2.1需求追踪矩阵.md`
    - CR、FR、场景到设计、组件、数据/API和测试证据的追踪基线。
13. `13-V2.1测试策略与验收基线.md`
    - 测试层级、场景断言、黄金数据、发布阻断和验收证据。
14. `14-V2.1开发启动与M0基线确认.md`
    - 记录V2.0上游标签、V2.1分支、M0冻结结果和M1首批开发顺序。

## 版本关系

- V2.0 原 S01—S08 场景保持不变，用于历史演示和向下兼容回归。
- V2.1 新场景独立编号 MT01—MT08。
- Demo、POC、Product 共用场景定义、核心契约和业务口径；客户交付版有客户后再映射真实机构、指标和数据。
- V2.1 仍限定为单域，不包含多域识别、跨域授权和跨域编排。

## 重新生成

文档源由 `scripts/generate-v2.1-multitask-docs.py` 维护。需要安装 `python-docx` 后运行该脚本；更新内容时必须重新执行结构和完整性校验。
