## 3. PostgreSQL待执行门禁

在隔离的空PostgreSQL数据库中设置以下环境变量后执行：

```bash
export ASKDATA_V21_POSTGRES_URL='jdbc:postgresql://host:5432/isolated_database'
export ASKDATA_V21_POSTGRES_USERNAME='migration_user'
export ASKDATA_V21_POSTGRES_PASSWORD='injected-secret'
bash scripts/v2.1-postgresql-migration-gate.sh
```

脚本拒绝非PostgreSQL JDBC URL，不内置数据库地址或密码。成功标准为服务使用真实PostgreSQL完成V1→V17迁移并启动，输出`POSTGRESQL_MIGRATION_GATE_PASS flyway=17`。V16真实库升级、备份恢复、权限授予和再次前滚仍需在同一隔离环境形成独立证据后，才能勾选T21-105。
