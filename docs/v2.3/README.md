# AskData 产品 V2.3 文档索引

V2.3定位为“单域开放治理平台版本”，从V2.2正式产品标签建立开发基线，扩展单域数据类型、企业治理、生态接口和管理端SQL助手。

## 文档

1. `01-AskData产品V2.3需求规格说明书.md`：产品范围、数据扩展、企业治理、生态开放、SQL助手、七层、数据、接口和四状态。
2. `02-AskData产品V2.3开发测试验收任务清单.md`：M0—M8开发、测试、验收、发布任务及退出条件。

## 边界

- 仍为单域版本，不建设多域能力包、跨域授权和跨域协同。
- SQL助手面向管理员，未验证SQL不执行、不出数、不进入普通用户答案。
- 新数据类型必须注册、审批、授权、限流、审计和版本化。
- Demo、POC、Product同步建设；Customer Delivery当前为空。
