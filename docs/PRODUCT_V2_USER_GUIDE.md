# 产品V2.0用户操作说明

产品V2.0保留“提问—澄清—执行—解读”的七层问数体验。用户身份、角色、机构/指标/表字段权限和当前发布版本在创建Session时形成不可变快照；后续请求不得自行提交或覆盖这些事实。

用户提交问题后，平台返回Request ID并通过SSE展示层级进度、结果或明确失败。断线时客户端使用`Last-Event-ID`续传，避免重复展示；收到429/503及`Retry-After`时应按指引退避，不能无界重试。用户可取消运行中请求，平台记录取消人、传播时间和最终状态。

场景7等缺参问题会在L2进入`WAITING_INPUT`：首轮只有L1/L2，不生成SQL或访问数据源。用户补齐机构、时间或指标后创建关联的新Request，并从L1重新执行；原首轮轨迹保持不变。

结果只代表当前Session的权限和配置快照。无权限、缺少Provider、SQL安全拒绝、模型或数据源异常均会明确显示状态，不会静默伪造成功。客户界面入口、单点登录方式和业务话术在M8确定后补充到客户版手册。
