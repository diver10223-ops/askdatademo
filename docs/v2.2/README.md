# AskData 产品 V2.2 文档索引

V2.2定位为“单域智能分析与主动服务版本”，从V2.1正式产品标签建立开发基线，复用任务计划、DAG、执行事实、证据链、权限和审计能力。

## 文档

1. `01-AskData产品V2.2需求规格说明书.md`：产品范围、智能分析、主动服务、七层、数据、接口、非功能、四状态和待确认事项。
2. `02-AskData产品V2.2开发测试验收任务清单.md`：M0—M7开发、测试、验收、发布任务及退出条件。

## 边界

- 单域，不建设跨域识别、跨域授权和跨域编排。
- 智能分析只消费可信执行事实，不临时执行未验证模型SQL。
- 主动服务必须在触发时重新校验订阅者权限。
- Demo、POC、Product同步建设；Customer Delivery当前为空。
