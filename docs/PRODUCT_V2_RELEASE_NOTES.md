# AskData产品V2.0发布说明

> 版本：2.0.0
> 发布类型：环境中立产品基线
> 客户交付状态：未完成；需按M8/M9适配与验收

## 主要能力

- Java控制面与Python七层执行面通过版本化内部契约集成；
- 身份、组织、角色权限、资产、场景、Provider引用、审批发布、审计、Session和运行事实进入规范化平台数据库；
- L2/L7 AI边界、AST SQL安全、权限快照、配置快照、幂等、取消和失败语义形成闭环；
- 公平准入、30/50执行槽、超载快速拒绝、可续传SSE、指标告警、归档及不可拆分备份恢复形成产品基线；
- 一期/二期稳定演示和POC基线继续由`v1-v2-poc-baseline-20260812`独立恢复，不依赖V2 Java服务。

## 升级说明

平台数据库使用Flyway V1—V16。V16只将产品元数据固化为`2.0.0/RELEASED`；任何已有迁移均不得修改。升级前必须按数据库迁移手册生成包含数据库、清单、匹配发布包、秘密恢复材料、Manifest和SHA256的完整恢复点，完成对账后再切流。

## 安全变化

Python依赖升级到通过当前漏洞库审计的版本；Java与Python内部调用、平台管理/执行入口不再提供默认令牌，数据库应用/迁移密码也不再提供默认值。除健康检查外，V2 API和Prometheus默认要求平台Bearer令牌；缺少安全配置时产品拒绝启动或内部调用，真实值必须由环境或秘密管理系统注入。

## 客户环境条件项

以下内容没有客户输入，保持`UNKNOWN/BLOCKED`，不包含在产品基线通过结论中：数据库品牌和版本、OIDC/SAML/LDAP、KMS/Vault、真实模型和数据源、网络/TLS/网关、监控通知、多实例共享准入、HA、RPO/RTO、数据保留、客户容量和业务签字。产品包中的H2、测试身份Provider和可控执行Stub证据不得冒充客户生产证据。

## 获取与恢复

正式Git标签、GitHub Release、产品归档及SHA256必须指向同一批准提交。V1.x演示使用稳定标签恢复；V2.0使用本发布包、匹配迁移和恢复手册恢复。禁止只恢复数据库或覆盖既有不可移动标签。
