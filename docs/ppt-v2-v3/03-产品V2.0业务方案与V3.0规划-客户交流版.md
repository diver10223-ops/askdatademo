## 统一视觉规范

- 16:9暖白/白底，全篇微软雅黑；封面40—54pt、页标题30—36pt、正文15—18pt、图表标注13—16pt。
- 正文墨蓝`#182033`，主色湖绿`#17745F`，辅色商务蓝`#5C91C8`，浅底`#F2F8F6`/`#EEF4FA`；橙色`#F47C3C`表示关键节点或待确认，不使用大面积高饱和色。
- 每页右上角可加“业务方案/产品能力/客户适配/演进规划”章节标签。
- 客户未知内容统一写“待调研确认”，不得用产品基线数据代替客户生产结论。

- 架构图统一按“顶部应用入口—中部平台能力—底部外部系统/数据”呈现；应用入口包括移动APP、移动小程序、企微应用、经营分析平台和企业门户/PC端，业务场景在用户端业务应用层表达。

## 第3页｜客户常见业务挑战

- 临时取数需求多、跨团队沟通周期长。

- 报表、驾驶舱和数据平台入口分散。
- 数据权限、敏感信息和SQL执行风险高。
- 问数过程难追溯，问题发生后定位困难。
- 大模型应用需要进入企业治理和审计框架。

## 第19页｜V2.0系统架构与交付边界

![技术架构图](assets/02-technical-architecture.svg)

**产品基线说明**

- Java控制面负责企业入口、身份权限、配置审批、发布回滚、运行主记录和审计。
- Python执行面负责固定七层问数链路；模型只参与L2理解和L7解读。
- 当前主要通过已发布指标与字段映射、受控SQL模板连接结构化数据源。
- V2.0以用户主动提问、事实查询、趋势对比和受控归因为主要业务形态。

**明确边界**：通用智能体、任意跨域编排、知识图谱、主动预测和业务写操作不属于V2.0已有交付能力；客户真实认证、数据库、模型、网络和业务口径仍须在目标环境验证。

**布局**：架构图占65%，右侧“产品已有/客户适配/不在V2.0范围”三段说明。

## 第20页｜V2.0与V3.0定位变化

| 对比维度 | V2.0产品基线 | V3.0规划能力 |
|---|---|---|
| 产品定位 | 安全可信自然语言问数平台 | 领域智能分析与决策协同平台 |
| 触发入口 | 用户主动提问 | 提问、订阅预警、智能报告和分析智能体 |
| 任务形态 | 一问一查或少量多SQL | 一问多查、多步骤、多数据源计划DAG |
| 业务组织 | 场景、指标和模板配置 | 领域能力包及可审批版本 |
| 数据范围 | 结构化数据库为主 | 数据库、业务API、文档、知识图谱和实时数据 |
| 结果输出 | 事实、表格、图表和追问 | 综合结论、异常归因、预测、证据和建议 |
| 治理重点 | 权限、SQL安全、事实一致性、审计 | 跨域授权、任务完整性、证据链和人工确认 |

**布局**：左右对比；V3.0所有内容标记“规划能力/待立项验证”。

## 第21页｜七层逐层演进对比

| 层级 | V2.0产品基线 | V3.0规划能力 |
|---|---|---|
| L1 | 请求封装、输入预检、会话和版本绑定 | 接入对话、订阅、预警、报告及智能体任务 |
| L2 | 要素提取、上下文、缺参歧义、权限合规初检 | 识别领域、能力、跨域需求及候选能力 |
| L3 | 口径归一、意图路由和语义查询计划 | 综合问题拆解、任务依赖、路径和完整性要求 |
| L4 | 数据源、表、字段和指标映射 | 授权API、文档、知识和实时数据资产匹配 |
| L5 | SQL模板及单/多SQL计划 | SQL/API/计算/检索组成的版本化计划DAG |
| L6 | SQL安全、数据范围注入和受控执行 | 串并行、限流、重试、取消、质量和部分成功 |
| L7 | 基于执行事实生成摘要、图表和归因 | 证据化结论、异常、预测、未核实项及建议 |

**布局**：三列表格；交流时结合客户目标场景确认V3.0优先层级，不将规划视为合同承诺。

## 第22页｜V3.0七层规划架构与边界

![V3.0七层规划架构](assets/21-v3-seven-layer-architecture.svg)

**页面文案**：L1交互与任务接入、L2领域理解、L3语义规划、L4可信资产匹配、L5查询与任务编排、L6执行与治理、L7证据化分析与决策辅助。

**治理边界**

- 模型不能裁决权限、绕过安全或创建未发布的跨域调用关系。
- L7只基于成功结果；权限不足、数据缺失和关键任务失败必须显著披露。
- “可信度”由证据完整性、数据时效、任务完成度和事实一致性表达，不由模型随意给出百分比。
- 支付、核销、关账、授权和配置发布等写操作必须跳转正式流程并重新鉴权、确认或审批。

**布局**：架构图占80%，右上角固定“V3.0规划能力”。

## 第23页｜V3.0后续拓展

**业务输入**：目标用户、优先场景、指标口径、黄金问题、验收标准。
