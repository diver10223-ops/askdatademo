## 版本依赖

```text
V2.0正式Product基线
  → V2.1 多任务优化、用户体验、多任务执行
    → V2.2 智能分析、主动服务
```

## 共同发布原则

- 每个版本管理Demo、POC、Product、Customer Delivery四种状态。
- 标准研发同步发布Demo、POC、Product；Customer Delivery当前为空，有客户后从已发布Product派生。
- 每个版本完整回归所有前序版本的标准场景。
- RC制品通过验收后原样晋升，正式发布不重新构建。
- 每项需求追踪到设计、代码、接口/库表、测试和验收证据。
- 每日修改统一写入`docs/DAILY_CHANGELOG.md`。
