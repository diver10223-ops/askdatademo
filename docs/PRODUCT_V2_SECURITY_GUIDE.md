# 产品V2.0安全说明

## 安全边界

- Java控制面负责身份权限、管理配置、审批审计、Session和运行事实；Python执行面负责七层引擎和Provider；
- 内部API使用独立服务令牌，外部V2管理/执行API和Prometheus使用另一个平台Bearer令牌，二者均至少32字节且无默认值；内部端点不得暴露公网，客户认证在M8由适配器替换；
- L2模型输出只作为受约束抽取候选，L7只生成通过事实一致性门禁的措辞；AI不裁决权限、安全、SQL执行或最终事实；
- SQL在执行前经AST白名单、字段/机构/时间谓词、复杂度、行数和Explain扫描量门禁；业务查询账号只读；
- 平台只保存秘密引用、版本和指纹，不保存秘密值或主密钥；日志、错误体和审计对敏感值脱敏；
- 审计链可检测篡改，但客户WORM/SIEM和数据库超级管理员审计仍需在M8接入。

平台Bearer令牌是环境中立基线的入口保护，不等同于最终用户单点登录，也不能单独证明`X-Actor-Id`的客户身份。客户交付必须在M8用OIDC/SAML/LDAP适配器和网关身份上下文替换共享令牌，并重新验证角色、组织范围和审计主体绑定；在此之前不得声明客户身份体系已经验收。

## 发布门禁

`scripts/v2-security-gate.sh`检查Git跟踪文件中的凭据形态和禁止文件，审计Python、前端生产及Java依赖，并重跑权限、SQL绕过、AI边界、Provider秘密、审批与防篡改审计专项测试。CVSS 7及以上Java漏洞、Python已知漏洞、前端高危/严重漏洞或任何真实凭据都会阻止发布。

产品包必须排除内部Skill、`CODEX_SKILLS_DESIGN.md`、提示词、客户数据、本地数据库、缓存、日志、`.env`、密钥和测试凭据。客户数据库、认证、KMS、网络、网关、监控、HA/RPO/RTO的真实安全验收在M8执行。
