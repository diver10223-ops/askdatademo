# 每日修改记录

> 本文件按自然日持续记录产品、代码、配置、测试和交付物调整。日期以工作区时区（UTC）为准；当天继续修改时追加到同一日期下，不覆盖历史记录。

## 记录规则

1. 每次完成一组修改后，当天同步追加“目标、变更内容、涉及文件、验证结果、遗留事项”。
2. 代码实现、产品方案、原型/PPT、配置和测试调整均须记录；仅讨论、尚未落地的内容标为“决策/规划”。
3. 每日结束前核对 `git status` 和当天新增、修改文件；已提交时补充提交号，未提交时明确标记“工作区未提交”。
4. 详细功能分析仍按 `修改分析/README.md` 的五类文档规范归档，本文件作为每日索引，不替代详细设计。
