# 产品V2.0管理员操作说明

产品V2.0的管理事实源是规范化平台数据库，官方JSON只用于初始化和灾备种子。管理员通过V2管理接口维护资产、场景和Provider非敏感配置；不得直接修改数据库事实表或双写旧JSON/SQLite。

## 日常流程

1. 维护机构、角色、权限范围、指标、维度、表字段和场景；
2. 创建秘密“引用”，真实秘密值只进入客户KMS/Vault；
3. 创建模型、数据源和运行Profile，完成诊断后才能启用；
4. 创建配置草稿，按流程审批并发布；新Session使用新版本，已有Session继续固定原快照；
5. 通过可观测摘要、告警、Trace和防篡改审计检查运行情况；
6. 回滚时创建新的发布记录，不覆盖历史快照；
7. 按恢复手册将平台库、发布包、秘密恢复材料和Manifest作为不可拆分单元备份/恢复。

超载响应429/503属于保护机制。调整全局并发、单用户并发、队列和数据库连接池前，应使用P372脚本重新验证，并记录客户Provider和数据库限额。生产迁移、发布、回滚、恢复和重置必须先确认目标、备份点和人工授权。

客户统一认证、审批人、通知渠道、监控平台、保留期、数据库分区和灾备参数属于M8条件项，不能以产品基线默认值代替。
